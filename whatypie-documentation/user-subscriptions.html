Overview

The User Subscriptions module allows administrators to monitor, manage, and analyze all active and past subscriptions on the WhatyPie WhatsApp marketing platform. This module provides insights into user subscription patterns and helps manage billing relationships.

Subscription Monitoring

  • Active Subscriptions: View all currently active subscriptions with details on plan, billing date, and payment status
  • Subscription History: Track all past subscriptions and cancellations
  • Payment Status: Monitor payment success/failure for each subscription
  • Renewal Dates: Track upcoming renewal dates for proactive management
  • User Details: See which users are subscribed to which plans

Management Capabilities

  • Subscription Modifications: Update user subscription plans when needed
  • Manual Renewals: Process renewals for users experiencing payment issues
  • Refund Processing: Handle refund requests and cancellations
  • Plan Upgrades/Downgrades: Manage transitions between different plan tiers
  • Analytics: Analyze subscription trends and user retention
