Authentication Creation Guide

Quickly configure your Authentication template by selecting the appropriate category and experience type.

Basic Setup

Navigate to Templates, select Custom, and set Category = authentication using standard naming (lowercase/numbers/underscores).


Message Body

Authentication content is strictly formatted. Use {{1}} for the OTP code and {{2}} for expiry minutes.

Verification Content *
"Your verification code is {{1}}. Valid for {{2}} minutes."

Marketing or promotional content is strictly prohibited in this category.

Button Text

The text shown on the OTP action button. Fixed to "Copy Code" for authentication templates. its mutable you can't change it.


OTP Configuration

Define the security parameters for your one-time passwords.

OTP Code Length

Choose between 4 to 8 digits for your security code.

Code Expiry

Set validity duration between 1 to 90 minutes.


Additional Options

Enhance security and branding with optional features.

Security Recommendation

Enable this to automatically append: "For your security, do not share this code."

Footer Text (Optional)

Add a secondary line at the bottom (max 60 characters).
