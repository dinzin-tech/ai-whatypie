1. Overview

Automation Flows are the core of your WhatsApp strategy. Using a visual, drag-and-drop interface, you can build complex customer journeys that respond instantly to triggers, reducing manual effort and maximizing customer engagement.

Efficiency Fact
Automated flows can handle up to 90% of routine customer inquiries, freeing your agents for high-value tasks.

2. Automation Builder Interface

The visual builder allows you to drag nodes from a library and connect them to create logic-based conversation paths.

Key Builder Components
  • Canvas: The workspace where you arrange and connect your nodes.
  • Trigger Nodes: Define how the flow starts (Keyword, Event, or API).
  • Action Nodes: Send messages, images, or interactive buttons.
  • Logic Nodes: Add conditions (If/Else) or delays to the flow.

3. Implementation Workflow

Follow these steps to build and activate your first automated workflow.

Step 1: Initiate Flow
  • Navigate to Automation Flows from the sidebar.
  • Click on + Create New Flow.
  • Enter a descriptive Flow Name (e.g., Welcome Bot).
Step 2: Build Logic
  • Drag a Keyword Trigger node onto the canvas.
  • Configure the keywords that should trigger this flow (e.g., "Hello", "Help").
  • Connect the trigger to a Message node.
Step 3: Save & Activate
  • Validate your connections (ensure every node has a path).
  • Click Save Flow at the top right.
  • Toggle the Status to Active to go live.
Example: Post-Purchase Engagement

A common scenario for e-commerce brands.

  • Trigger: Order Status updated to "Delivered".
  • Action: Send a "How did we do?" message with review buttons.
  • Logic: If [Positive] → Send coupon; If [Negative] → Notify agent.

4. Governance & Best Practices

Logic Optimization
  • Default Fallbacks: Always include a path for when conditions aren't met.
  • Human Handover: Ensure one path leads to a live agent for complex issues.
  • Testing: Test keywords from multiple sandbox accounts before release.

Note: Flows with high drop-off rates often have too many steps. Keep your conversational paths concise and valuable.
